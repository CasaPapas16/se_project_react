# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react/README.md) uses [Babel](https://babeljs.io/) for Fast Refresh
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react-swc) uses [SWC](https://swc.rs/) for Fast Refresh

### Overview

- intro to react
- dymanic weather application
- filtering of clothes options
- accurate weather tracking

**Intro**

This project is focus on providing information to the user of accurate weather data and the suggestions on what to wear for the day. Things to look out for is how the weather data that is provided and filtering the items to choose from.

**weather**

It currently brings up one city, I hope to implement a funcitonnal tracker that you will be able to open the app anywhere and provide the correct data.

**popup modals**

The user has the ability to click on the filtered image to bring up the item they want to look at. The user can also click on the add clothes button to input and add inventory for additional items.
